# Moon-vibe sells — راهنمای راه‌اندازی

وب‌اپ مدیریت فروش و انبار مون وایب. روی گوشی (اندروید و آیفون) نصب می‌شود. بدون اینترنت کار می‌کند و هر وقت اینترنت وصل باشد، دو گوشی را با هم همگام می‌کند.

---

## ۱. میزبانی (لازم برای کار کردن دوربین)

مرورگرها دوربین را فقط روی آدرس **https** باز می‌کنند. پس این پوشه باید روی یک هاست با https قرار بگیرد. اپ کاملاً استاتیک است: نه سرور می‌خواهد و نه دیتابیس روی هاست. فقط فایل‌ها کپی می‌شوند.

**پیشنهاد اول: لیارا (ایرانی، بدون فیلتر)**
1. در liara.ir ثبت‌نام کنید و یک برنامه از نوع **Static** بسازید.
2. ابزار خط فرمان لیارا را نصب کنید: `npm i -g @liara/cli`
3. داخل همین پوشه دستورهای زیر را بزنید:
   - `liara login`
   - `liara deploy --platform static --app <نام-برنامه>`
4. آدرس `https://<نام-برنامه>.liara.run` آماده است.

**راه سریع‌تر برای تست (ممکن است بدون VPN باز نشود):**
پوشه را در app.netlify.com/drop بکشید و رها کنید.

> جزئیات پنل و تعرفه‌ی هاست‌ها ممکن است عوض شده باشد. هر هاست استاتیکی که https بدهد کار می‌کند.

## ۲. نصب روی گوشی
- **آیفون:** آدرس را در **Safari** باز کنید ← دکمه‌ی Share ← **Add to Home Screen**.
- **اندروید:** آدرس را در **Chrome** باز کنید ← منوی ⋮ ← **Install app** یا «افزودن به صفحه‌ی اصلی».
- اولین بار که دکمه‌ی اسکن را می‌زنید، اجازه‌ی دوربین را بدهید.

## ۳. راه‌اندازی اولیه
- **گوشی اول:** «راه‌اندازی فروشگاه جدید» را بزنید ← نام، کد کاربر (مثلاً `M`) و رمز ۴ رقمی را وارد کنید.
- **همگام‌سازی:** تنظیمات (دکمه‌ی اسلایدر روی داشبورد) ← همگام‌سازی ابری ← ثبت‌نام با ایمیل ← «ساخت فروشگاه». یک **کد اتصال ۶ حرفی** نمایش داده می‌شود.
- **گوشی دوم:** «اتصال به فروشگاه موجود» را بزنید ← کد کاربر **متفاوت** بگذارید (مثلاً `H`) ← با ایمیل خودش ثبت‌نام کند ← کد اتصال را وارد کند.

شماره‌ی فاکتورها با کد ثبت‌کننده ساخته می‌شود (`M-1001`، `H-1001`). به همین دلیل دو گوشی هیچ‌وقت شماره‌ی یکسان نمی‌سازند.

## ۴. نکات مهم
- **تأیید ایمیل:** Supabase بعد از ثبت‌نام یک لینک تأیید به ایمیل می‌فرستد. اگر نمی‌خواهید این مرحله باشد: Supabase Dashboard ← Authentication ← Sign In / Providers ← Email ← گزینه‌ی **Confirm email** را خاموش کنید.
- **دسترسی از ایران:** سرور همگام‌سازی (Supabase، فرانکفورت) ممکن است بدون VPN در دسترس نباشد. اپ در این حالت هم کامل کار می‌کند؛ فقط همگام‌سازی تا وصل شدن صبر می‌کند و نوار «آفلاین · موجودی‌ها ممکن است دقیق نباشند» نمایش داده می‌شود.
- **پروژه‌ی رایگان Supabase:** اگر حدود یک هفته از آن استفاده نشود، متوقف (pause) می‌شود. با فروش روزانه‌ی دایرکت این اتفاق نمی‌افتد. اگر افتاد، از داشبورد Supabase آن را Restore کنید؛ داده‌ها از بین نمی‌روند.
- **پشتیبان:** تنظیمات ← «پشتیبان (فایل)» را هر چند وقت یک بار بزنید. داده‌ها روی گوشی هم ذخیره‌اند.
- **بارکدخوان:** روی اندروید از اسکنر داخلی Chrome استفاده می‌کند و روی آیفون از ZXing. بارکدهای EAN-13، EAN-8، UPC، Code128، Code39، ITF و QR خوانده می‌شوند. اگر دوربین تار دید، دکمه‌ی زوم (×۲) یا چراغ قوه را بزنید. ورود دستی بارکد هم همیشه هست.

## ۵. به‌روزرسانی اپ
بعد از هر تغییر در فایل‌ها، مقدار `CACHE` را در `sw.js` عوض کنید (مثلاً `v1.0.1`) و دوباره deploy کنید. گوشی‌ها پیام «نسخه‌ی جدید آماده است» را نشان می‌دهند.

## ساختار
| فایل | کار |
|---|---|
| `index.html`، `css/app.css` | رابط کاربری و سیستم طراحی |
| `js/app.js` | صفحه‌ها و رویدادها |
| `js/logic.js` | موجودی، فاکتور، مرجوعی، روز غرفه، گزارش |
| `js/db.js` | ذخیره‌سازی آفلاین (IndexedDB) و صف همگام‌سازی |
| `js/sync.js` | همگام‌سازی با Supabase |
| `js/scanner.js` | بارکدخوان |
| `supabase/schema.sql` | طرح دیتابیس (روی پروژه اعمال شده است) |

اتصال Supabase: پروژه‌ی `moon-vibe-sells` با آدرس `https://tshukvlmonkenrlcyfrx.supabase.co`. کلید publishable داخل `js/sync.js` است. این کلید عمومی است و امنیت با RLS تأمین می‌شود.
